# 🎵 Discord Music Bot

Um bot de música para o Discord desenvolvido em Python, com suporte a reprodução de áudio, filas e comandos de controle via voz.

---

## 🚀 Funcionalidades

- Reprodução de áudio via YouTube/URLs com extração via `yt-dlp` e `FFmpeg`
- Gerenciamento de fila de músicas (`play`, `skip`, `stop`, `queue`, `pause`, `resume`)
- Estrutura modular utilizando Cogs do `discord.py`

---

## 🛠️ Pré-requisitos

- **Python 3.10+**
- **FFmpeg** instalado e adicionado ao `PATH` do sistema
- Token de bot criado no [Discord Developer Portal](https://discord.com/developers/applications)
